# basic

串口、引脚
外设：GPIO、ADC模数转换、DMA存储器访问、FSMC灵活控制、中断实时事件响应、串口usart、PWM脉宽调制输出、uart都属于外设模块
引脚gpio、tx、rx、GND

# usart模块内部结构
在usart模块内部

时钟模块、中断模块、发送数据寄存器、接收数据寄存器、数据帧格式、

rx接收数据串口
tx发送数据串口

中断模块的0/1标识位（如txe、tc、rxne、pe、FE、NE、ORE）可以反映usart模块的当前状态
TxE标志位、Tc标志位与数据发送有关 
RxNE标志位、PE标志位与数据接收有关

RxNE：receive data register not empty接收数据寄存器非空
当RDE非空时，RxNE=1；否则RxNE=0.
# 使用串口发送数据
发送数据的时候，八位数据位的字节从tx串口出去，在移位寄存器里，一个比特位一个比特位地被发送出去，这样就发送出了第一个字节。

编程接口
```c
//控制usart模块的使能和禁止，相当于总开关
USART_Cmd( )
USART_Cmd(USARTx,ENABLE)；//使能
USART_Cmd(USARTx,DISABLE)；//禁止
```
获取标志位的当前状态
USART_GetFlagStatus(USARTx,USART_FLAG_TXE)

# 使用串口接收数据
接收数据的时候，八位数据位的字节从rx串口进来，在移位寄存器里，一个比特位一个比特位地被接受到接收数据寄存器里，这样就接收到了第一个字节，可以从接收数据寄存器读取 这一个数据。

# 串口数据帧的格式
起始位+8-9位数据帧/比特位+停止位+奇偶校验位
