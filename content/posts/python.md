库-包-模块-函数：

函数function 放在 模块 里
模块 放在 包 里
包 组成 库lib

```text
Python 标准库（自带）
├── urllib（包）
│   ├── urllib.request（模块）→ urlopen()（函数）
│   ├── urllib.parse（模块）
│   └── urllib.error（模块）
├── json（模块）
├── csv（模块）
└── os（模块）

第三方库（需 pip 安装）
├── requests
├── beautifulsoup4
└── playwright
```

urllib 是 python 标准库的一个包
