# how to make a pcb

## what is a pcb

A PCB(Printed Circuit Board)  is a physical electronic circuit board that contains electronic components, interconnects, and other features.

A minimum system board(MCU core board/development core board ) is a sepecific type of PCB that contains a MCU, power supply, and basic peripherals.
